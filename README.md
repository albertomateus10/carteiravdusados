# Dashboard de Monitoramento de Trocas (VD) - Grupo San Marino

Este projeto é um dashboard moderno e responsivo para monitorar carros que entram na troca de vendas diretas (VD), consumindo dados em tempo real de uma planilha do Google Sheets.

## 🚀 Funcionalidades

- **Indicadores em Tempo Real**: Total de veículos, valor total avaliado e ticket médio.
- **Filtros Avançados**: Filtros por Loja, Ano e Mês para análise detalhada.
- **Busca Rápida**: Campo de pesquisa por modelo, vendedor ou placa.
- **Design Premium**: Interface escura com estética moderna e layout responsivo.
- **Sincronização**: Botão para atualizar os dados diretamente da planilha sem recarregar a página.

## 🛠️ Tecnologias Utilizadas

- HTML5 Semântico
- CSS3 (Vanilla) com Variáveis e Modern Layouts (Flexbox/Grid)
- JavaScript (ES6+) para integração e manipulação de DOM
- Font Awesome para ícones
- Google Fonts (Inter) para tipografia

## 📋 Como Usar

### Pré-requisitos
Para evitar erros de segurança do navegador (CORS) ao buscar dados da planilha, recomendamos rodar o projeto em um servidor local.

### Link da Planilha
O projeto consome os dados da seguinte planilha: [Acesse aqui](https://docs.google.com/spreadsheets/d/1ZXum0nBBdqZSwIddWKTyh5IUswc20KHGdyvB36mGh_Q/).

### Publicação no GitHub Pages
Este projeto é ideal para ser hospedado no **GitHub Pages**:
1. Crie um repositório no GitHub.
2. Faça o upload dos arquivos `index.html`, `style.css` e `script.js`.
3. Vá em **Settings > Pages**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde o link ser gerado.
